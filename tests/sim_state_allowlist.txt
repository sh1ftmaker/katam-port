# Writable host objects in simulation translation units that are NOT
# simulation state -- tools/check_sim_state.py (make lint-simstate).
# Everything else a sim unit writes lives in the GBA map or the port sim block
# (platform/port/simblock.h).  One line each:  UNIT SYMBOL CLASS REASON
#
# Classes:
#   const-init   a constant table; C++ (LP64) initialises it at startup because
#                its P32 members have no constexpr constructor, so it lands in
#                .data/.bss.  Never written afterwards.
#   boot-init    a pointer table filled once at boot from link-time constants
#                (the *_init pattern in the fork), identical every run.
#   const-write  written during play, but always with the same constant value.
#   never-written declared writable, written by nothing.
#   setting      a session setting; the recording/session carries it as input.
#   diagnostic   counts or reports the run, never read by the game.
#   host-state   simulation state that cannot be GBA bytes because it holds
#                host pointers; the snapshot serialises it canonically.
#   presentation audio/video output state (NETPLAY-V2 §3.1 class P).
