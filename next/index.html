Tilemap
The GBA drew 240×160 and the game is built around that number in five separate places — the display, the sprite list, the object cull, the spawn window and the camera clamp. Zooming in is a crop of a real picture and cannot be wrong. Widening asks for world the game never copied into video memory:hardware wrapis what a naive widening shows (the room from 32 tiles ago, repeated),blankis that admitted, andread the room’s mapgoes back to the level data the copy was made from and draws what should have been there.
Enemies
Rules
Every enemy is one byte in the room’s level data, so this swaps the byte as the room loads and the game builds a different enemy in the same spot from its own code — graphics and palette included, because KATAM loads those when an object is created rather than per room. A seed is the whole run: the same number gives the same game every time.Takes effect at the next door, since the room you are standing in already has its list.Match enemy sizeskeeps a room’s video-memory demand near what it was built for — turning it off is the setting that can overflow the tile heap. Bosses are the risky pool and are off by default.
